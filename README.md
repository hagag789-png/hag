# محافظي كاش — تطبيق أندرويد

تطبيق أندرويد أصلي يعرض برنامج «محافظي كاش» ويحفظ بياناتك على الهاتف (بدون حساب أو إنترنت)،
مع نسخ احتياطي واستعادة ومشاركة وتصدير CSV.

## الحصول على ملف APK

### الطريقة 1 — بناء سحابي بضغطة واحدة (الأسهل، مجاني، من الهاتف)
1. أنشئ حسابًا على github.com إن لم يكن لديك.
2. أنشئ مستودعًا جديدًا (New repository) باسم `mahafez-cash` — عام أو خاص.
3. ارفع كل ملفات هذا المجلد إليه (Add file → Upload files، اسحب المجلد كاملًا).
4. افتح تبويب **Actions** → سيعمل «Build APK» تلقائيًا (3–5 دقائق).
5. عند الانتهاء افتح **Releases** في صفحة المستودع → نزّل `MahafezCash.apk` على هاتفك وثبّته.
   (قد يطلب الهاتف السماح بالتثبيت من مصادر غير معروفة — اسمح له).

### الطريقة 2 — Android Studio على الكمبيوتر
1. ثبّت Android Studio، ثم File → Open → اختر هذا المجلد.
2. Build → Build Bundle(s) / APK(s) → Build APK(s).
3. الملف في `app/build/outputs/apk/release/app-release.apk`.

### الطريقة 3 — من سطر الأوامر (مع Android SDK مثبّت)
    ./gradlew assembleRelease

## أين بياناتي؟
داخل التطبيق فقط (WebView localStorage). حذف التطبيق يحذفها، لذلك استخدم زر
«نسخة احتياطية» في أعلى الشاشة بانتظام؛ النسخ تُحفظ في Downloads/MahafezCash.

## تعديل البرنامج
واجهة البرنامج كلها في `app/src/main/assets/index.html` — عدّلها وأعد البناء.
